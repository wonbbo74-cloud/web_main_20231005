# 🎮 LoL 테마 웹사이트

리그 오브 레전드를 주제로 만든 웹 페이지입니다. 웹 프로그래밍 수업에서 HTML/CSS/JavaScript와 Bootstrap으로 화면을 구성하고, 쿠키·세션 스토리지·암호화 등 클라이언트 측 기능을 단계별로 실습하며 만들었습니다.

## 주요 기능

- **메인 페이지**: 네비게이션 바, 게임 정보 메뉴, 인기 챔피언 카드·이미지
- **검색**: 입력한 검색어로 새 창에서 구글 검색
- **팝업 & 시계**: 접속 시 공지 팝업, "오늘 하루 보지 않기" 쿠키, 실시간 시계
- **로그인**
  - 아이디 저장 쿠키
  - DOMPurify를 이용한 XSS 입력값 검사
  - 로그인 정보를 CryptoJS(AES-256)로 암호화해 세션 스토리지에 저장
- **회원가입**: 클래스(`SignUp`) 기반 입력값 처리, 가입 완료 페이지
- **로그아웃**: 세션 스토리지 삭제 후 메인으로 이동
- **프로필 페이지**: 사용자 정보 카드
- **지도**: 카카오맵 API로 위치 표시

## 사용 기술

`HTML5` `CSS3` `JavaScript (ES6)` `Bootstrap 5.3` `CryptoJS` `DOMPurify` `Kakao Maps API`

## 폴더 구조

```text
├── index.html          # 메인 페이지
├── login/              # 로그인, 회원가입, 로그아웃, 프로필 페이지
├── popup/              # 팝업 페이지
├── js/
│   ├── login.js        # 로그인, XSS 검사, 쿠키
│   ├── join.js         # 회원가입
│   ├── session.js      # 세션 스토리지 저장/조회
│   ├── security.js     # AES-256 암복호화
│   ├── cookie.js       # 쿠키 저장/조회
│   ├── popup.js        # 팝업, 시계
│   ├── search.js       # 검색
│   └── map.js          # 카카오맵
├── css/
└── image/
```

## 실행 방법

VS Code의 **Live Server** 확장으로 `index.html`을 열면 됩니다. (지도 기능은 카카오 API 키가 필요합니다.)
